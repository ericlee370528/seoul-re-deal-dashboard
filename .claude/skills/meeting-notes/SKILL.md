# 회의록 정리

회의 메모(음성 전사, 메모, 채팅 로그 등 비정형 텍스트)를 입력받아 핵심만 구조화한 회의록으로 정리한다.

## 절차

1. 입력된 회의 메모 전체를 읽고 다음 세 가지를 분류한다.
   - **결정사항**: 회의에서 확정되거나 합의된 내용
   - **할 일 (Action Item)**: 앞으로 수행해야 할 작업
   - **담당자**: 각 할 일을 맡은 사람. 메모에 명시되지 않으면 "미정"으로 표기하고, 추측하지 않는다.
2. 각 할 일에 기한(마감일)이 언급되어 있으면 함께 기록한다. 언급이 없으면 "미정"으로 표기한다.
3. 잡담, 배경 설명, 결론 없는 논의 등은 결과물에서 제외한다. 결정되지 않고 보류된 안건은 "보류 사항"으로 별도 표기한다.
4. 프로젝트 CLAUDE.md 규칙을 따른다.
   - 표는 마크다운 표 문법으로 작성한다.
   - 금액이 언급되면 억원 단위로 환산하여 표기하고, 옆에 계산식이나 원문 근거를 함께 표기한다. (예: 12.5억원 = 원문 "12억 5천만원")
   - 전체 출력은 결론(요약)을 최상단에 배치한 뒤 표를 제시한다.

## 출력 형식

```
## 요약
(회의의 핵심 결론을 1~3문장으로 요약)

## 결정사항
| 결정사항 | 비고 |
| --- | --- |
| ... | ... |

## 할 일 및 담당자
| 할 일 | 담당자 | 기한 |
| --- | --- | --- |
| ... | ... | ... |

## 보류 사항 (있는 경우에만)
| 안건 | 사유 |
| --- | --- |
| ... | ... |
```

## 주의사항

- 메모에 없는 내용을 추론하거나 담당자를 임의로 배정하지 않는다.
- 담당자가 여러 명이면 쉼표로 모두 나열한다.
- 회의 메모가 여러 개(여러 파일 또는 여러 세션)로 주어지면, 각 표에 출처(회차/날짜)를 구분할 수 있는 열을 추가한다.
